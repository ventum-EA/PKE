# Chess Piece SVG Sets

Each subfolder contains 12 SVGs: wK.svg, wQ.svg, wR.svg, wB.svg, wN.svg, wP.svg,
bK.svg, bQ.svg, bR.svg, bB.svg, bN.svg, bP.svg

The ChessBoard component loads pieces as <image> elements using the pattern:
  /pieces/{style}/{color}{piece}.svg

Available styles: cburnett (default)
